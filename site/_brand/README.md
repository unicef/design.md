# Brand Assets

This directory contains logo assets used by the Quarto demo site.

- `unicef-logo-cyan-horizontal.png`, `unicef-logo-white-horizontal.png`, and `unicef-logo-centered.png` are copied from the approved English logo assets in `files/`.
- `_brand-light.yml` and `_brand-dark.yml` now point to those approved PNGs.
- The placeholder SVG files remain only as fallback demo assets.
