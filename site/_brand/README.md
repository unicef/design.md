# Brand Assets

This directory contains logo assets used by the Quarto demo site.

- `unicef-logo-cyan-horizontal.png`, `unicef-logo-white-horizontal.png`, `unicef-logo-cyan-vertical.png`, `unicef-logo-white-vertical.png`, and `unicef-logo-centered.png` are copied from the approved English logo assets in `files/`.
- `_brand-light.yml` and `_brand-dark.yml` point to horizontal logos for the navbar and vertical logos for the sidebar.
- The placeholder SVG files remain only as fallback demo assets.
